<h1>PerfectJobAnalysis – Job Market Analysis Dashboard</h1>

<h3>📌 Project Overview</h3>

PerfectJobAnalysis is a Python-based job market analysis project that collects job-related data through web scraping, cleans and processes the data using Pandas and NumPy, and presents meaningful insights through a web-based dashboard. The application is developed using Flask, HTML, and CSS, with visualizations created using Matplotlib and Seaborn to analyze job availability, company ratings, and city-wise job trends.

<h4>🎯 Objectives</h4>

Analyze job market data to identify useful trends and patterns.

Clean and preprocess raw data for accurate analysis.

Explore job availability across different cities and companies.

Visualize insights through charts and graphs.

Build a web-based dashboard for easy data exploration.

<h4>✨ Key Features</h4>

Web Scraping: Collects job-related information from web sources.

Data Cleaning: Processes missing values and inconsistencies.

Interactive Dashboard: Displays key metrics and visualizations.

Company Analysis: Explores company information and ratings.

City-wise Analysis: Examines job-related trends across locations.

Data Filtering: Filters available records based on selected criteria.

Data Visualization: Presents insights through charts and graphs.

<h4>🛠️ Technologies Used</h4>

Programming Language: Python

Data Analysis: Pandas, NumPy

Data Visualization: Matplotlib, Seaborn

Backend Framework: Flask

Frontend: HTML, CSS
